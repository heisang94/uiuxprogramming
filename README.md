# CloudStep | 클라우드 학습 가이드 (12주차 과제)

## 1. 서비스 소개
CloudStep은 클라우드·시스템 엔지니어 입문자가 Linux, Network, Docker/Kubernetes, AWS 학습 계획을 만들고 추천 주제를 선택하는 학습 가이드 웹 서비스입니다. 11주차까지 만든 기능과 저장 데이터 형식을 유지하고, 12주차에는 재사용 가능한 UI 컴포넌트를 정리했습니다.

## 2. 구현한 재사용 UI 컴포넌트와 사용 방법

### 컴포넌트 A: 탭(Tab)
- **사용 위치:** 주요 기능 화면의 `학습 로드맵 / 핵심 기술 정리 / 실습 가이드`
- **사용 목적:** 여러 학습 설명을 같은 영역에서 선택해 확인
- **작동:** 탭 클릭 시 해당 패널만 표시하고 `aria-selected`, `tabindex`, `.is-active`, `hidden`을 함께 갱신
- **재사용 구조:** `initTabs(tablist)`는 각 `role="tablist"` 안의 탭과 `aria-controls`로 연결된 패널을 찾아 독립 초기화합니다. 다른 탭 그룹도 동일한 구조로 추가할 수 있습니다.
- **키보드:** Tab으로 진입, 좌/우 방향키 및 Home/End로 탭 전환

### 컴포넌트 B: 아코디언(Accordion)
- **사용 위치:** 자주 묻는 질문 화면의 3개 질문
- **사용 목적:** 많은 안내 내용을 필요할 때만 펼쳐 읽도록 구성
- **작동:** 질문 클릭 시 답변 표시/숨김, `aria-expanded`, `.is-open`, 기호(+/−) 변화
- **재사용 구조:** `.accordion-item` 묶음을 추가하면 `initAccordion(container)`가 같은 방식으로 동작을 연결합니다. `aria-controls`와 답변 `id`를 일치시킵니다.
- **키보드:** Tab으로 질문 버튼 이동, Enter/Space로 펼치기·접기

### 컴포넌트 C: 저장 계획 카드(Card)
- **사용 위치:** 저장한 학습 계획 화면
- **사용 목적:** 학습 계획이 여러 개여도 동일한 카드 구조와 상태 표시 제공
- **작동:** 진행 중/취소됨 상태에 따라 레이블·버튼·색상 변화, 전체/진행 중/취소됨 필터와 연동
- **재사용 구조:** `createArchiveCard(plan)`은 계획 데이터 1건을 `li` 카드로 생성하고 `renderArchive()`가 항목 수만큼 재사용합니다. 실제 데이터는 기존 `localStorage` 키 `cloudstep-plans`를 사용합니다.
- **키보드:** Tab으로 카드별 버튼에 접근, Enter/Space로 취소/재진행

## 3. 공통 디자인 및 접근성
- `:root`의 `--component-radius`, `--component-gap`, `--component-focus`로 공통 간격·모서리·초점 색상을 관리합니다.
- 주요 조작 버튼은 `min-height: 48px`로 맞췄습니다.
- `:focus-visible` 외곽선과 실제 HTML `button`을 사용하고, 선택/펼침 상태를 ARIA 속성에 동기화합니다.
- 600px 이하에서는 아코디언 패딩을 조정하고 기존 모바일 탐색 메뉴를 유지합니다.
- 기존 다크 모드에서도 같은 컴포넌트를 사용할 수 있게 색상 규칙을 추가했습니다.

## 4. 이전 기능 유지
학습 계획 3단계, 입력 검증 및 저장 상태, 분야별 추천, `cloudstep-plans` 저장, 저장 목록 필터 및 취소/재진행, 테마 전환, 이메일 신청 시연, 반응형 메뉴와 접근성 기능을 유지했습니다.
