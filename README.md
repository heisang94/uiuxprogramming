# CloudStep | 클라우드 학습 가이드 (11주차 과제)

## 1. 서비스 소개
CloudStep은 클라우드·시스템 엔지니어 입문자가 Linux, 네트워크, Docker/Kubernetes, AWS의 학습 순서와 실습 목표를 계획하는 웹 서비스입니다.
기존 단계별 학습 계획, 분야별 추천, 로컬 저장, 저장 목록 필터, 반응형 메뉴를 유지하며 웹 접근성을 개선했습니다.

## 2. 11주차 접근성 개선: 개선 전 → 개선 후
1. **현재 메뉴와 필터 구분**: 개선 전에는 현재 위치와 선택 상태가 주로 배경색으로 표시되었습니다. → 개선 후에는 굵기·밑줄을 추가하고 기존 `aria-current`, `aria-pressed`를 유지해 색상에 의존하지 않습니다.
2. **이미지 대체 설명**: 개선 전에는 이미지의 학습 장면을 간단하게 설명했습니다. → 개선 후에는 이미지에 어떤 장면이 있는지 구체화한 `alt`를 제공하고 `width`, `height`도 지정했습니다. 실제 이미지 내용과 문장이 일치하는지 배포 전에 확인합니다.
3. **키보드로 본문 이동**: 개선 전에는 페이지 상단 메뉴들을 모두 지나야 본문으로 이동할 수 있었습니다. → 개선 후에는 첫 Tab에서 `본문 바로가기` 링크가 나타나고 Enter를 누르면 `<main id="top" tabindex="-1">`으로 이동합니다.
4. **모바일 메뉴 종료와 초점 복귀**: 개선 전에는 메뉴를 닫으려면 버튼이나 링크를 눌러야 했습니다. → 개선 후에는 열린 모바일 메뉴에서 Esc를 누르면 닫히며 메뉴 버튼으로 초점이 돌아옵니다. `aria-expanded`도 갱신됩니다.
5. **계획 필터 안내와 카드 초점**: 개선 전에는 필터 개수만 안내되고 카드 취소 시 초점이 사라질 수 있었습니다. → 개선 후에는 `aria-live` 상태 문구로 결과 유무를 알리고, 취소한 카드가 사라지면 필터 버튼으로 초점을 이동합니다. 결과가 없을 때는 `전체 보기`도 제공됩니다.
6. **브라우저 제목과 읽기 쉬운 대비**: 개선 전에는 메뉴를 이동해도 탭 제목이 고정되어 있었습니다. → 개선 후에는 선택한 메뉴 이름으로 탭 제목을 바꾸고 안내 문구 대비 및 키보드 초점 외곽선을 강화했습니다.

## 3. 유지한 기존 기능
- 주요 메뉴 7개와 모바일 메뉴, 현재 위치 표시
- 학습 계획 입력 검증, 3단계 작성, 저장 중/완료/실패 안내
- `localStorage`의 `cloudstep-plans` 저장 키 및 이전 데이터 호환
- 저장 목록 전체/진행 중/취소됨 필터와 상태 변경
- 맞춤 학습 추천, 테마 전환, 탭, 이메일 신청 시연

## 4. 브라우저 최종 확인표
다음 항목은 **직접 확인한 후** `[x]`로 바꾸세요.
- [ ] 첫 Tab → '본문 바로가기' 표시, Enter → 본문 이동, 다음 Tab 이동
- [ ] 메뉴를 누를 때 밑줄·굵기가 바뀌고 주소 및 브라우저 탭 제목이 갱신됨
- [ ] 전체/진행 중/취소됨 필터에서 선택 밑줄과 결과 안내가 보임
- [ ] 취소된 계획이 현재 필터에서 사라지면 초점이 선택 필터에 남음
- [ ] 빈 결과에서 '전체 보기'를 선택하면 전체 필터와 초점이 복구됨
- [ ] 600px 이하 모바일에서 메뉴 열기 → Esc 닫기 → 버튼 초점 복귀
- [ ] 테마 변경 후 텍스트와 버튼·초점 대비를 육안으로 확인
- [ ] 계획 이름을 비운 채 진행하면 오류 안내 및 입력 초점 표시
- [ ] 계획 저장 → 새로고침 → 저장 목록 확인, 취소/재진행
- [ ] 이미지가 정상 표시되고 `alt` 내용이 실제 이미지와 일치함
- [ ] 데스크톱과 모바일에서 기존 학습 추천·탭·이메일 기능 정상 동작
- [ ] GitHub에 푸시한 뒤 실제 배포 주소에서 동일하게 확인
