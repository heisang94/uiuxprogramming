# CloudStep | 클라우드 학습 가이드 (10주차 과제)

## 1. 서비스 및 목표
CloudStep은 클라우드·시스템 엔지니어 입문자를 위한 학습 가이드 웹페이지입니다. 9주차의 단계별 계획 작성, 폼 검증, 브라우저 저장, 맞춤 추천을 유지하면서 메뉴와 저장 목록 탐색 경험을 개선했습니다.

## 2. 이번 주 추가·수정한 기능
- **주요 내비게이션**: 서비스 소개 / 주요 기능 / 학습 방법 / 학습 계획 만들기 / 저장한 계획 / 맞춤 학습 추천 / 소식 받기, 총 7개 링크. 각 링크의 `href`는 실제 `section`의 `id`에 연결됩니다.
- **현재 위치 표시**: 주소 해시(`location.hash`)에 대응하는 메뉴 링크 하나에 `is-current`와 `aria-current="location"` 적용. `hashchange` 이벤트로 뒤로 가기·앞으로 가기에도 표시를 동기화하고, 해시가 없으면 첫 메뉴를 선택합니다.
- **저장 목록 필터**: `전체`, `진행 중`, `취소됨` 3개 버튼. `aria-pressed`와 선택 색상 동기화. 기존 `cloudstep-plans` 로컬 저장소에서 데이터를 읽고 조건별 카드와 결과 개수·빈 목록 안내를 표시합니다.
- **계획 상태 변경**: 저장된 카드의 '계획 취소하기'/'다시 진행하기' 버튼으로 `cancelled` 상태를 바꿉니다. 이전 9주차 저장 데이터에 `cancelled` 값이 없으면 진행 중으로 해석합니다. 저장 시 목록을 즉시 다시 그립니다.
- **모바일 메뉴**: 화면 너비 600px 이하에서 메뉴 열기/닫기 버튼 표시. `is-open`, 버튼 글자, `aria-expanded`가 연동되며 링크 클릭 시 메뉴가 닫힙니다.

## 3. 유지한 기존 기능
- 1~6주차: 테마 전환, 주요 기능 탭, 이메일 신청 시연
- 7~8주차: 학습 계획 입력 및 분야·수준별 맞춤 추천, 선택·취소·확정
- 9주차: 입력 검증, 조건부 실습 목표, 저장 중/성공/실패 처리
- 기존 저장 키 `cloudstep-plans` 유지. 데이터는 현재 브라우저의 `localStorage`에만 저장됩니다.

## 4. 직접 확인할 테스트 순서
아래 항목을 실제 브라우저에서 확인한 후 `[x]`로 바꿉니다.

- [ ] PC에서 7개 메뉴가 각각 올바른 영역으로 이동한다.
- [ ] 처음에는 첫 메뉴만 강조되고, 메뉴 이동 및 브라우저 뒤로 가기 시 강조가 갱신된다.
- [ ] 기존에 저장한 계획이 있으면 새로고침 후에도 저장한 계획에 표시된다.
- [ ] 계획 2개 이상 저장하고 한 개 취소한 뒤 전체·진행 중·취소됨 필터의 카드와 개수를 확인한다.
- [ ] 빈 결과에서는 필터에 맞는 안내가 나타나고 다른 필터로 이동할 수 있다.
- [ ] 화면 너비 600px 이하에서 메뉴 버튼이 나타나고 누를 때마다 열기/닫기 문구와 목록이 바뀐다.
- [ ] 모바일에서 메뉴 링크를 누르면 해당 영역으로 이동하고 메뉴가 닫힌다.
- [ ] PC·모바일에서 테마, 9주차 검증·저장, 추천·탭·이메일 기능이 그대로 동작한다.
- [ ] GitHub Pages에서 새로고침 및 테스트를 반복한다.

## 5. 배포 및 제출
`index.html`, `style.css`, `script.js`, `README.md`를 기존 GitHub 프로젝트 같은 위치에 덮어쓰고 커밋·푸시합니다. 기존 이미지 `assets/images/cloud-study.jpg`는 삭제하지 않습니다.
강의실에 안내된 방식대로 **GitHub 저장소 주소와 배포된 웹페이지 주소**를 제출합니다.

## 6. 주의사항
학습 계획은 서버가 아닌 `localStorage` 저장 시연입니다. 브라우저 저장 데이터를 지우면 목록도 삭제될 수 있습니다. 이메일 신청은 실제 발송 기능이 아닙니다. 실제 테스트 완료 여부는 제출 전 직접 확인해야 합니다.
