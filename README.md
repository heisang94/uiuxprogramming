# CloudStep | 클라우드 학습 가이드 (7주차)

## 서비스 소개
CloudStep은 클라우드 및 시스템 엔지니어링을 처음 학습하는 사람을 위한 입문 가이드 웹페이지입니다. Linux, Network, Docker/Kubernetes, AWS 등 주요 기술을 소개하고, 개인 학습 계획을 직접 만들 수 있습니다.

## 사용자와 목표
- **주요 사용자:** 클라우드·시스템 엔지니어 분야의 초보 학습자
- **사용자 목표:** 이름, 관심 분야, 학습 수준을 선택하여 개인 학습 계획 완성
- **완료 조건:** 입력/선택한 값이 확인 화면에 정확히 표시되고 '학습 계획이 완성되었습니다!' 화면에 도달

## 사용자 흐름 및 인터랙션 시나리오
| 순서 | 행동 | 이벤트 / 조건 | 화면 반응 |
| --- | --- | --- | --- |
| 시작 | 학습 계획 만들기 클릭 | `click` | 단계별 화면 열기 |
| 1단계 | 이름 입력 후 다음 | `click` / 이름 비어 있음 | 오류 안내 및 현재 단계 유지 |
| 1단계 | 이름 입력 후 다음 | `click` / 정상 입력 | 2단계 이동 |
| 2단계 | 분야와 수준 선택 | `change` / 값 변경 | 선택 상태 반영 |
| 2단계 | 선택 누락 상태에서 다음 | `click` / 선택 누락 | 오류 안내 및 현재 단계 유지 |
| 2단계 | 정상 선택 후 다음 | `click` / 선택 완료 | 확인 화면에 입력값 표시 |
| 수정 | 이전 단계로 이동 | `click` | 입력값 유지한 채 이전 단계 표시 |
| 완료 | 학습 계획 완성 클릭 | `click` | 완료 메시지 표시 |
| 다시 시작 | 다시 만들기 클릭 | `click` | 입력/선택/오류/요약 초기화 |

## 주요 구현 기능
- 기존 서비스 소개, 탭 전환, 다크 모드, 이메일 글자 수 표시·동의·신청 유지
- 7주차 학습 계획: 시작 → 이름 입력 → 분야/수준 선택 → 내용 확인 → 완료
- 필수 입력/선택 검증과 수정 안내, 잘못된 항목으로 포커스 이동
- 이전 단계 이동 시 기존 값 유지, 완료 후 다시 시작 시 초기화
- 모바일(768px 이하, 390px 이하) 반응형 스타일

## 테스트 체크리스트
다음 항목은 **배포 후 직접 확인하고 결과를 표시**합니다. 현재 체크되지 않은 항목은 테스트 완료를 의미하지 않습니다.

- [ ] 정상 흐름: 시작 → 입력 → 선택 → 확인 → 완료
- [ ] 이름 미입력: 오류 문구 노출 및 다음 단계 이동 차단
- [ ] 분야/수준 누락: 오류 문구 노출 및 다음 단계 이동 차단
- [ ] 수정: 이전 단계로 이동했을 때 기존 값 유지
- [ ] 수정 후 재확인: 변경 값이 확인 화면에 반영
- [ ] 다시 시작: 이름·분야·수준·오류·요약 모두 초기화
- [ ] 모바일: 좁은 화면에서 입력·버튼이 화면 밖으로 넘치지 않음
- [ ] 기존 기능: 탭 UI, 테마 변경, 이메일 신청 정상 동작
- [ ] GitHub Pages: 배포된 사이트에서 같은 동작 확인

## 실행 방법
`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행합니다. 정적 HTML/CSS/JavaScript로 동작하며 별도 서버가 필요하지 않습니다.

> 이메일 신청과 학습 계획 완료는 프론트엔드에서 화면 상태만 변경하는 시연 기능이며, 서버나 데이터베이스에 저장하거나 실제 이메일을 발송하지 않습니다.
