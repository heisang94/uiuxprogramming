# CloudStep | 클라우드 학습 가이드 (8주차 중간평가)

## 1. 서비스와 사용자 목표

CloudStep은 클라우드·시스템 엔지니어 분야를 처음 공부하는 학습자를 위한 입문 가이드 웹페이지입니다. Linux, Network, Docker/Kubernetes, AWS의 학습 방향을 안내합니다.

- **주요 사용자:** 클라우드·시스템 엔지니어 분야의 초보 학습자
- **목표:** 학습 계획을 만들고 자신의 관심 분야와 현재 수준에 맞는 학습 항목을 선택합니다.
- **완료 조건:** 개인 학습 계획 완성 후 맞춤 추천 항목 중 하나를 선택하고 '학습 항목 선택이 완료되었습니다!' 화면까지 도달합니다.

## 2. 7주차 결과물과 8주차에 추가한 기능

**7주차 유지:** 서비스 소개, 주요 기능 탭, 학습 방법, 다크 모드, 이메일 신청 시연, 단계별 개인 학습 계획(이름 입력 → 분야·수준 선택 → 계획 확인 → 완료), 이전 단계 수정과 초기화.

**8주차 신규:** '맞춤 학습 추천' 영역을 추가했습니다. 7주차의 학습 계획 완료 이후에만 추천 항목이 표시되며 관심 분야와 학습 수준에 따라 제안하는 학습 항목이 달라집니다. 사용자는 항목을 선택해 설명을 확인한 뒤 학습 시작 항목을 확정하거나, 선택을 취소하거나, 다른 항목으로 다시 선택할 수 있습니다. 학습 계획을 다시 만들면 추천 상태도 함께 초기화됩니다.

> 이번 8주차 신규 기능은 6주차의 단순 테마·글자 수 변경과 다르며, 7주차 학습 계획의 결과값을 새로운 행동(맞춤 학습 항목 선택)에 연결합니다.

## 3. 사용자 흐름과 인터랙션 시나리오

| 단계 | 사용자 행동 | 이벤트·조건 | 화면 반응 / 다음 상태 |
| --- | --- | --- | --- |
| 진입 전 | 추천 영역 확인 | 학습 계획 미완료 | 학습 계획을 먼저 완료하라는 안내 표시 |
| 계획 완료 | 7주차 계획 완료 클릭 | `click` · 입력과 선택 정상 | 추천 영역 해제, 분야·수준에 맞는 추천 목록 생성 |
| 추천 이동 | 맞춤 추천 확인 클릭 | `click` | 추천 영역으로 스크롤 및 첫 항목에 초점 |
| 학습 항목 선택 | 추천 카드 클릭 | `click` | 선택한 항목 강조 및 설명·확정·취소 표시 |
| 확정 | 학습 시작하기 클릭 | `click` · 항목 선택됨 | 최종 선택 완료 화면 표시 |
| 선택 취소 | 선택 취소 클릭 | `click` | 항목 선택 표시와 미리보기 초기화, 목록으로 복귀 |
| 다시 선택 | 다른 항목 선택하기 클릭 | `click` | 선택 완료 상태 해제 후 추천 목록 표시 |
| 추천 초기화 | 추천 선택 초기화 클릭 | `click` | 추천 선택 상태만 초기화, 7주차 학습 정보는 유지 |
| 전체 초기화 | 계획 다시 만들기 클릭 | `click` | 이름·분야·수준·추천 선택 모두 초기화 |
| 결과 없음 | 추천 데이터에 일치 항목 없음 | 조건 검사 | 안내 문구 표시; 현재 제공하는 유효한 분야·수준 조합에는 모두 데이터가 있어 일반 UI에서는 발생하지 않는 방어 처리 |

## 4. 추천 조건

분야별로 3개의 순서 있는 학습 주제를 준비하고, 수준에 따라 추천 시작 지점을 달리합니다.

| 학습 수준 | 추천 범위 |
| --- | --- |
| 입문 | 기초부터 3개 항목 |
| 기초 학습 경험 있음 | 중간 단계부터 2개 항목 |
| 실습 경험 있음 | 심화 단계 1개 항목 |

추천 내용은 클라이언트 JavaScript에 포함된 안내용 예시 데이터이며 실제 학습 진단, 서버 추천, 수강 신청을 수행하지 않습니다.

## 5. 입력·상태·피드백

- 이름이 비어 있으면 1단계에 머무르며 오류 문구를 표시합니다.
- 학습 분야 또는 수준을 누락하면 2단계에 머무르며 누락된 항목을 표시합니다.
- 이전 단계로 돌아가도 입력값이 유지됩니다.
- 새 기능은 학습 계획 완료 전에 잠겨 있으며, 완료 후 목록·선택·미리보기·완료 상태로 전환됩니다.
- 선택 취소 또는 다른 항목 선택 시 이전 추천 선택 상태를 해제합니다.
- 학습 계획을 다시 만들면 기존 추천 상태까지 초기화합니다.
- 동적으로 입력한 이름은 `textContent`로 출력해 HTML로 처리하지 않습니다.

## 6. 테스트 체크리스트

아래 항목은 **배포 후 브라우저에서 직접 확인하고** 성공한 항목만 `[x]`로 변경해 제출합니다. 체크되지 않은 항목은 아직 사용자가 검증하지 않았다는 의미입니다.

- [ ] 정상 경로: 이름 입력 → 분야/수준 선택 → 계획 완료 → 추천 카드 선택 → 항목 확정
- [ ] 입력 오류: 이름 없이 다음 클릭 → 오류 표시 및 이동 차단
- [ ] 선택 오류: 분야/수준 미선택 → 오류 표시 및 이동 차단
- [ ] 오류 수정: 누락 항목을 선택하면 남은 오류 상태가 올바르게 반영됨
- [ ] 이전·수정: 이전 단계로 이동 시 이름과 선택값 유지, 수정 후 확인 화면 반영
- [ ] 추천 잠금: 7주차 계획 미완료 시 추천 항목 비공개
- [ ] 추천 분기: 분야에 따라 추천 주제가 달라짐
- [ ] 추천 분기: 입문 3개, 기초 경험 2개, 실습 경험 1개 표시
- [ ] 추천 선택: 카드 선택 시 미리보기와 확정 버튼 노출
- [ ] 취소: 선택 취소 후 강조 표시·미리보기 제거
- [ ] 완료: 확정 시 선택한 학습 항목명이 완료 문구에 표시
- [ ] 재선택: 완료 후 다른 항목 선택 가능
- [ ] 추천 초기화: 학습 정보는 유지하면서 추천 선택만 초기화
- [ ] 전체 초기화: 계획 다시 만들면 추천 영역이 다시 잠기고 입력값 삭제
- [ ] 반응형: PC와 모바일에서 버튼/카드/입력창 겹침 없이 사용 가능
- [ ] 기존 기능: 탭·키보드 탭 이동·다크 모드·이메일 신청 정상 작동
- [ ] 배포: GitHub Pages에서 로컬과 같은 흐름으로 동작

## 7. 실행 방법

`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행합니다. 정적 HTML·CSS·JavaScript이므로 별도 서버나 데이터베이스 없이 화면 기능이 작동합니다.

기존 7주차의 이미지 파일 `assets/images/cloud-study.jpg`를 동일 경로에 유지해야 서비스 소개 이미지가 표시됩니다. 이 전달본에는 기존 이미지 원본이 포함되어 있지 않습니다.

> 학습 소식 신청과 학습 계획 완료, 추천 항목 선택은 화면에서만 작동하는 시연 기능입니다. 실제 이메일 발송이나 서버 저장은 진행되지 않습니다. 새로고침하면 상태가 초기화됩니다.
