# CloudStep

클라우드 엔지니어 입문자를 위한 학습 가이드 서비스입니다.

## 사용자

클라우드 및 시스템 엔지니어 분야를 처음 공부하는 초보자입니다.

## 사용자 목적

Linux, Network, Docker, Kubernetes, AWS 등
클라우드 관련 기술의 학습 순서와 주요 내용을 이해하는 것이 목적입니다.

## 페이지 구조

1. 서비스 소개
2. 주요 기능
3. 학습 방법
4. 소식 받기

## 구현하면서 바꾼 구조

처음에는 단순히 서비스 소개와 기능만 보여주는 구조를 생각했습니다.

하지만 사용자가 페이지를 처음 방문했을 때
서비스가 무엇인지 이해한 뒤,
어떤 기능이 있는지 확인하고,
실제 학습 방법을 본 다음
소식 신청으로 이어지는 흐름이 자연스럽다고 판단했습니다.

그래서 다음과 같은 순서로 구성했습니다.

서비스 소개 → 주요 기능 → 학습 방법 → 소식 받기

## 변경 이유

화면을 단순히 꾸미는 것보다
사용자가 정보를 어떤 순서로 읽고
어디로 이동할지 이해하기 쉽게 만드는 것을 우선했습니다.

또한 주요 기능은 목록 형태로 구성하여
각 기능을 빠르게 확인할 수 있도록 했습니다.
