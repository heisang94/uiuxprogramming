# CloudStep | 클라우드 학습 가이드 (9주차 과제)

## 1. 서비스와 사용자 목표
CloudStep은 클라우드·시스템 엔지니어 입문자를 위한 학습 가이드 웹페이지입니다. 학습자는 이름, 관심 분야, 현재 학습 수준, 선택적 실습 목표를 입력하여 학습 계획을 저장하고 맞춤 학습 항목을 선택할 수 있습니다.

- 주요 사용자: 클라우드·시스템 엔지니어 분야의 입문자
- 주요 흐름: 계획 시작 → 이름 입력 → 분야·수준 선택 → 선택적 실습 목표 설정 → 입력 확인 → 저장 → 맞춤 추천 → 학습 항목 선택
- 기술: HTML5, CSS3, Vanilla JavaScript, GitHub Pages, localStorage

## 2. 기존 기능 및 9주차 수정 내용
- 7주차: 단계별 학습 계획 작성, 이전 단계 이동, 초기화
- 8주차: 관심 분야·학습 수준별 학습 항목 추천 및 선택·취소·확정
- 9주차: 기존 학습 계획 영역을 `<form id="planForm" novalidate>`으로 구성하고 입력 필드의 연결·검증·조건부 입력·저장 상태를 추가

### ① 서비스에 맞는 폼 구성
- 이름: `label for="planName"`과 `input id="planName" name="name"`; 필수, 2~30자
- 분야 및 수준: 각각 연결된 `label`과 `select`; 필수
- 선택적 실습 목표: `practiceOption` 체크박스와 `fieldset id="practiceOptions"`, `legend`, 라디오 3개
- 제출 버튼: `type="submit"`으로 선언하고 `form`의 `submit` 이벤트로 처리
- 오류·안내는 `aria-describedby`, `aria-invalid`, `role="alert"`, `role="status"` 등으로 연결

### ② 조건부 입력
- '추가 실습 목표도 설정하겠습니다' 체크박스를 선택하면 `practiceOptions.hidden = false`가 됩니다.
- 숨겨진 동안 라디오 요소는 `disabled=true`로 설정되어 키보드 포커스 및 제출 대상에서 제외됩니다.
- 체크를 해제하면 영역이 닫히고 저장 데이터에서도 추가 목표가 제외됩니다.
- 체크 상태에서 실습 목표를 선택하지 않으면 다음 단계로 이동할 수 없습니다.

### ③ 입력 검증 및 피드백
- 이름의 입력 글자 수를 `0 / 30자` 형식으로 실시간 표시합니다.
- 미입력, 1자 입력, 2자 이상 입력을 구분하여 안내합니다.
- 적절한 입력은 초록 테두리와 문구, 오류 입력은 빨간 테두리와 구체적인 메시지로 표시합니다.
- 입력 중 무조건 오류를 표시하지 않고, 다음 단계 이동 시 검증한 뒤 오류를 수정하면 다시 검사합니다.
- 분야 및 수준은 선택 누락에 따라 오류가 표시되고 수정하면 다시 검증합니다.

### ④ 제출 상태 처리
- 최종 단계의 제출 버튼은 `type="submit"`입니다. 버튼과 Enter 키로 같은 이벤트 흐름을 사용합니다.
- 제출 검증 후 저장 중에는 `aria-busy="true"`, 버튼 비활성화 및 '저장하는 중...' 메시지가 표시됩니다.
- `isSaving`으로 중복 제출을 차단합니다.
- 성공하면 저장 완료 메시지와 추천 영역을 표시합니다.
- 실패하면 입력값을 지우지 않고 오류 메시지를 표시하며 재시도할 수 있습니다.
- 시연용 저장은 `localStorage`를 사용합니다. 실제 서버 저장은 수행하지 않습니다.
- `?save-error=1` 쿼리 문자열을 붙여 열면 저장 실패 흐름을 시험할 수 있습니다.

### ⑤ 완료 및 재작성
- 완료 화면에서 추천 학습 항목으로 이동할 수 있습니다.
- '계획 다시 만들기'는 이름·분야·수준·조건부 선택·안내 문구·추천 상태를 초기화합니다.
- 이전에 브라우저에 저장된 계획 목록은 삭제하지 않습니다(현재는 조회 UI가 없는 단순 저장 시연입니다).

## 3. 직접 확인할 순서
아래 항목은 **브라우저에서 직접 확인 후** 통과한 항목을 `[x]`로 바꿉니다.

- [ ] '학습 계획 만들기' → 이름 미입력으로 다음 단계 시도: 오류 메시지와 포커스 이동
- [ ] 이름 1자 입력 후 다음: 최소 2자 오류 메시지
- [ ] 2자 이상 입력 시 글자 수 및 정상 상태 확인
- [ ] 분야 또는 수준 누락 상태로 다음 클릭: 오류 표시 및 이동 차단
- [ ] 체크박스를 선택하면 추가 실습 목표가 보이고 라디오 선택 가능
- [ ] 체크박스를 해제하면 추가 영역이 숨겨지고 라디오가 비활성화됨
- [ ] 체크한 상태에서 목표를 선택하지 않으면 다음 이동 차단
- [ ] 3단계에서 이름·분야·수준·실습 목표가 올바르게 표시됨
- [ ] 저장 중 버튼과 뒤로 가기 버튼이 잠기고 저장 중 문구가 나타남
- [ ] 정상 저장 후 완료 화면과 맞춤 추천이 표시됨
- [ ] `?save-error=1`로 열면 실패 메시지, 입력값 유지, 버튼 재활성화 확인
- [ ] 다시 만들기 시 조건부 영역 및 입력 상태가 초기화됨
- [ ] PC·모바일, 밝은 테마·어두운 테마, 기존 탭·추천·이메일 기능 확인
- [ ] 배포된 GitHub Pages에서 동일하게 확인

## 5. 참고사항
이메일 신청은 기존 화면 시연이며 실제 메일을 보내지 않습니다. 학습 계획은 브라우저 로컬 저장소에만 기록됩니다. 브라우저나 저장 공간을 삭제하면 보관 데이터가 삭제될 수 있습니다. 다른 기기와 동기화하지 않습니다.
