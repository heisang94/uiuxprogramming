# CloudStep

클라우드 엔지니어 입문자를 위한 학습 가이드 서비스입니다.

## 사용자

클라우드 및 시스템 엔지니어 분야를 처음 공부하는 초보자입니다.

## 사용자 목적

Linux, Network, Docker, Kubernetes, AWS 등
클라우드 관련 기술의 학습 순서와 주요 내용을 이해하는 것이 목적입니다.

## 페이지 구조

1. 서비스 소개
2. 주요 기능
3. 학습 방법
4. 소식 받기

## 구현하면서 바꾼 구조

처음에는 단순히 서비스 소개와 기능만 보여주는 구조를 생각했습니다.

하지만 사용자가 페이지를 처음 방문했을 때
서비스가 무엇인지 이해한 뒤,
어떤 기능이 있는지 확인하고,
실제 학습 방법을 본 다음
소식 신청으로 이어지는 흐름이 자연스럽다고 판단했습니다.

그래서 다음과 같은 순서로 구성했습니다.

서비스 소개 → 주요 기능 → 학습 방법 → 소식 받기

# 3주차 CSS 수정 기록

## 수정한 내용

주요 기능 영역의 학습 로드맵, 핵심 기술 정리, 실습 가이드를
가로로 배치하기 위해 `.feature-list`에

각 기능을 한눈에 비교하기 어려웠습니다.

Flexbox를 사용해 세 기능을 같은 그룹으로 배치하고
일정한 간격을 적용했습니다.

## 사용자 이점

사용자는 CloudStep에서 제공하는 주요 기능을
한 화면에서 빠르게 확인하고 비교할 수 있습니다.

# 4주차 반응형 수정 기록

## 확인한 문제

기존 페이지는 넓은 화면을 기준으로 구성되어 있어서
모바일 화면에서는 메뉴와 기능 카드가 좁아지고,
서비스 소개 영역과 이메일 입력 영역을 사용하기 불편했습니다.

## 수정한 내용

viewport 메타 태그를 확인하고
전체 콘텐츠에 width: 100%와 max-width를 적용했습니다.

네비게이션에는 flex-wrap을 적용하여
화면이 좁아질 때 메뉴가 자연스럽게 줄바꿈되도록 했습니다.

주요 기능 영역은 기존 Flexbox에서 Grid로 변경하고
auto-fit과 minmax를 사용하여
화면 너비에 따라 카드 개수가 자동으로 조정되도록 했습니다.

또한 768px 이하에서는
네비게이션, 기능 카드, 서비스 소개 영역,
이메일 입력창과 버튼이 세로로 배치되도록 수정했습니다.

## 확인한 화면 크기

- 1100px
- 769px
- 768px
- 390px

## 달라진 점

1100px과 769px에서는 기존의 넓은 화면 구성을 유지하면서
기능 카드가 화면 크기에 맞게 자동으로 배치됩니다.

768px 이하에서는 메뉴와 기능 카드가 한 열로 배치되고,
서비스 소개 이미지와 이메일 입력 영역도
모바일 화면에 맞게 세로로 정렬됩니다.

390px 화면에서도 가로 스크롤 없이
모든 내용을 확인하고 입력할 수 있습니다.

## 프로젝트 소개

CloudStep은 클라우드 및 시스템 엔지니어 분야를 처음 공부하는 학습자를 위한 웹페이지입니다.

Linux, Network, Docker, Kubernetes, AWS 등의 기술을 소개하고 단계별 학습 방법을 안내합니다.

6주차에는 기존 반응형 웹페이지에 JavaScript 이벤트와 동적 UI 기능을 추가했습니다.

## 사용 기술

* HTML5
* CSS3
* JavaScript
* Visual Studio Code
* Git / GitHub

## 6주차 구현 기능

1. click 이벤트 - 테마 전환

* 테마 변경 버튼을 클릭하면 밝은 테마와 어두운 테마가 전환됩니다..

* classList.toggle()로 body의 클래스를 변경합니다.

* 현재 테마에 맞춰 버튼 문구도 변경됩니다.


2. input 이벤트 - 이메일 글자 수 표시

* 이메일 입력창에 글자를 입력하면 글자 수가 실시간으로 변경됩니다.

* 입력 가능한 최대 글자 수는 100자입니다.

* value.length와 textContent를 사용했습니다.


3. change 이벤트 - 체크박스 상태 변경

* 학습 소식 안내 동의 체크박스를 선택하면 신청 버튼이 활성화됩니다.

* 선택 여부에 따라 안내 문구와 스타일이 변경됩니다.

* checked, disabled, classList를 사용했습니다.


4. 탭 UI 구현

* 주요 기능을 세 가지 탭으로 구성했습니다.
    - 학습 로드맵
    - 핵심 기술 정리
    - 실습 가이드

* 탭 버튼을 클릭하면 연결된 콘텐츠만 나타납니다.

* querySelectorAll(), forEach(), data-target을 사용했습니다.


5. 이메일 신청 기능

* 이메일을 입력하지 않으면 오류 문구가 나타납니다.

* 이메일 형식이 올바르지 않으면 안내 메시지가 출력됩니다.

* 올바른 이메일과 동의 여부를 확인하면 신청 완료 상태로 변경됩니다.

* 중복 신청을 방지하기 위해 신청 버튼을 비활성화합니다.

* 실제 이메일 발송이나 서버 저장은 구현하지 않았습니다.


## 반응형 웹

* CSS 미디어 쿼리를 사용하여 화면 크기에 따라 레이아웃이 변경되도록 작성했습니다.

    - 1100px: 데스크톱 기본 레이아웃
    - 768px: 메뉴와 콘텐츠 영역의 모바일형 배치
    - 390px: 작은 모바일 화면의 간격 및 글자 크기 조정

## 학습 정리

이번 과제를 통해 JavaScript 이벤트가 사용자의 행동과 화면 변화를 연결하는 방법을 학습했습니다.
특히 click, input, change 이벤트의 차이를 이해하고, 여러 버튼과 콘텐츠를 연결하는 탭 UI를 구현하면서 DOM 요소 선택과 상태 변경 방법을 연습했습니다.
